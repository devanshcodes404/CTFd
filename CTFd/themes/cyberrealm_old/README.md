# CyberRealm

CyberRealm is a custom CTFd theme inspired by modern cybersecurity learning
platforms such as TryHackMe and Hack The Box.

This project is being developed using:

- CTFd 3.8.6
- Vite
- SCSS
- JavaScript

Future roadmap:

- Gaming setup wizard
- Animated UI
- Dynamic dashboards
- React frontend migration
